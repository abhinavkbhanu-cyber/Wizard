# RB22

RB22 is a separate PC product from **RB22 Game Booster Pro**.

## v0.1 Alpha

The first standalone shell establishes the product architecture for:
- AI Game Optimizer
- Game Library
- Performance / Hardware
- Memory
- Network Auto/Manual DNS
- Benchmark
- Keyboard Auto-Key
- Custom Hotkeys
- Per-application profiles
- Input Lab
- Angle Snapping
- Mouse Auto-Clicker
- Desktop / Productivity / Custom profiles
- Global enable/disable architecture

This alpha intentionally keeps advanced hardware changes and game-specific automation behind dedicated modules so they can be tested independently without destabilizing the existing Game Booster Pro project.
