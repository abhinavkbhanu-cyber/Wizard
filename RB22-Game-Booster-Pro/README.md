# RB22 Game Booster Pro
Universal Windows 10/11 gaming utility.

## Build
GitHub Actions automatically publishes a self-contained Windows x64 single EXE on every push to main. Open Actions, select the successful Build RB22 Windows EXE run, then download the artifact.

## Included
- Dark moon/night UI
- F8 overlay
- Four network endpoints: Cloudflare, Google, Quad9, OpenDNS
- Automatic latency test
- Laptop/desktop detection label
- Windows performance-mode hook
- CPU/RAM monitoring
- No ads or analytics

FPS is reported only when a reliable frame source is available; this starter build does not invent FPS values. Network endpoint latency is not the same thing as game-server latency.
